# Task 02: Background Color Changer

## Project Introduction

This is my second project in the JavaScript 50 Mini Projects challenge.

In this project, I created a Background Color Changer using HTML, CSS, and JavaScript.

Users can change the webpage background color by clicking different buttons.

## Features

- Change background to Red.
- Change background to Green.
- Change background to Blue.
- Change background to Black.
- Change background to Yellow.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Learned

### 1. getElementById()

Used to select HTML elements using their IDs.

```javascript
let red = document.getElementById("red");
```

### 2. addEventListener()

Used to handle button click events.

```javascript
red.addEventListener("click", function () {
    // Code
});
```

### 3. DOM Manipulation

Used to dynamically change the background color of the webpage.

```javascript
document.body.style.backgroundColor = "red";
```

### What I Learned

- How to select multiple HTML elements.
- How click events work.
- How to change CSS properties using JavaScript.
- How to manipulate the DOM.
- How to use event listeners.
